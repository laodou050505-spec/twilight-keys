# 新曲目格式（每首一个 JSON 文件，放在本目录）

全部必须是**公有领域**：作曲家去世超过 70 年的作品，或传统民歌 / 童谣。编曲由你自己写（不要照抄某个现代出版的编曲）。
不要写：电影 / 游戏 / 流行歌，1950 年以后的作品，作曲家 1955 年以后去世的作品（例如《梁祝》《彩云追月》都不行）。

```json
{
  "id": "moonlight",                       // 小写英文、唯一；不能和曲库已有 id 重复
  "title": "月光奏鸣曲",                     // 中文曲名（常用译名）
  "subtitle": "Moonlight Sonata · Beethoven（1801）",   // 一行副标题：英文名 · 作曲家（年份）；民歌写国家
  "en": "Moonlight Sonata",                // 英文曲名（英文界面显示）
  "category": "classical",                 // classical 巴洛克 / 古典时期；romantic 浪漫派 / 近代（印象派等）；folk 各国民歌；kids 童谣 / 节日
  "composer": "Ludwig van Beethoven (1770–1827)",
  "pd": "作曲家 1827 年去世，作品 1801 年出版；编曲为本项目原创",
  "difficulty": 2,                          // 1 简单 / 2 中等 / 3 难（按 score 的密度和跳动）
  "bpm": 60,                                // 一拍 = 记号里时值 1 的长度
  "meter": 4,                               // 每小节几拍（3/4 写 3；6/8 按附点四分为一拍写 2；3/8 写 1.5）
  "score": "……",                            // 玩家跟弹的谱（音块）：见下
  "master": "……"                            // 大师演奏的完整编曲：见下
}
```

## 记号

空格分隔，每个记号一个块。`|` 是小节线（必须写，校验器按它数拍）。
- `E4` 一拍；`E4:2` 两拍；`E4:0.5` 半拍；`E4:0.25` 十六分；三连音写 `:0.333`、`:0.333`、`:0.334`（加起来要正好 1）。
- `E4+C3+G3` 同时发声。**第一个音是旋律**（游戏按它分到四条轨道、决定哪个琴键亮），后面是伴奏。
- 一个记号里几组错开发声：`E4+C3,G3@0.5,C5+E3@1:2`（时值 2 拍；第二组在 0.5 拍、第三组在 1 拍时发声）。`~G3@0.5` 表示这一组没有旋律、轻一点。
- 降号可以写 `Bb4`、`Eb5`；`E#`、`B#`、`Cb`、`Fb` 也认。音域 A0（21）到 C8（108）。

## score（跟弹谱）

- 玩家用手指在桌上敲，一个记号 = 一个音块。**每个记号最短 0.18 秒**（= 时值 × 60 / bpm）；太密的音写进 master，score 里合并成长一点的记号。
- 24 到 260 个记号，时长 20 到 240 秒（一般 40–100 秒最好：完整的主题，一段或两段）。
- 旋律至少用到 5 个不同音高（四条轨道是按旋律音高的高低排的）。
- 伴奏写在 `+` 后面（低音 + 和弦音），让玩家敲的每一下都好听；长音可以 `:2` `:3`。

## master（大师演奏，用来欣赏）

- 和 score **同一段音乐、同一个 bpm、同一个拍号、总拍数完全相等**（两份谱同时开始、同时结束；小节数一样）。
- 写成像钢琴家弹的完整版：双手、和弦、分解和弦、低音线、装饰音、八度；**越丰富越好、键位越多越好**（音符总数至少是 score 记号数的 1.6 倍，一般 3–6 倍）。
- 不限速度（十六分、三十二分都行），但要好听、和声对、两手不打架（同时发声别超过 8 个音）。

## 校验

写完跑：`python3 Tools/chart_check.py Tools/songs_extra/<id>.json`，必须打印 OK。

## 给曲库已有的歌补 master

文件名 `master_<id>.json`：`{"id": "canon", "patch": true, "meter": 4, "master": "……"}`。master 总拍数要和曲库里那首的 score 一致（`Assets/_Twilight/Resources/songs.json` 里能看到原 score）。
